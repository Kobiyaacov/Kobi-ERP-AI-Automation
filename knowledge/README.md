# הידע שמאחורי התשובה

**12 מסמכי מדיניות והנחיות · קטלוג של 34 מוצרים ושירותים**

כאן נמצאים חומרי המקור שסופקו לפרויקט מצפן ERP: המדיניות של עסק ההדגמה, הנחיות לסוכנים וקטלוג המוצרים. כך אפשר לראות לא רק את תשובת הבוט, אלא גם את המידע שמיועד לתמוך בה.

## קטלוג המוצרים

**[פתיחת קטלוג המקור: products.csv](products/products.csv)**

הקובץ מכיל 34 רשומות וחמישה שדות: `Name`, `Category`, `Price`, `Description`, `InStock`. התיאורים כוללים מפרטים, שימושים, אחריות ותנאי שירות כפי שנמסרו במקור.

הקובץ הוא מקור לטעינת ידע, לא חיבור למלאי חי. טעינתו למאגר ה־RAG אינה מסנכרנת אוטומטית את טבלת `Products` ב־Airtable.

<details>
<summary><strong>על המקורות והיקף ההדגמה</strong></summary>

הקבצים חולצו מחבילות `policies` ו־`products` שסופקו לפרויקט, ונשמרו ללא שינוי בתוכן ובשמות. אלה חומרי דמו לימודיים, לא הנחיה משפטית או חשבונאית מעודכנת; פרטי העסק והתקשורת הם חלק מתרחיש ההדגמה.

המקורות כוללים גם תכנון רחב יותר, כגון פתיחת החזרות, מעקב משלוחים וניתוח תזרים. עצם הופעת פעולה במסמך אינה מעידה שמומשה באפליקציה. המימוש המתועד מפורט במפת התהליכים.

התיקייה אינה ייצוא של המאגר הווקטורי, ואינה מאשרת שכל אחד מהמסמכים נטען להרצה האחרונה. העלאת הקבצים ל־GitHub אינה משנה את מאגרי הידע הפעילים ב־n8n.

</details>
